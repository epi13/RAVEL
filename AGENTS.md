# Agent contract

- Begin with bounded family context and current `mncs-language` and Commons
  identities; do not rediscover family architecture by scanning sibling repos.
- RAVEL application semantics land in the native `mncs/` tree first. Query
  language capabilities and existing Commons pressures before retaining or
  adding Python/Rust behavior.
- Python, C, and Rust outside native MNCS are allowed only as explicit
  compatibility, transport/platform, bootstrap, reference, or differential
  oracle surfaces. They must not silently decide RAVEL semantic outcomes.
- Query Commons before creating a pressure, preserve evidence/status
  boundaries, and keep `UNKNOWN` distinct from failure or completion.
